# Synthetic public bill-classification corpus

`cases.jsonl` and `cases.template.jsonl` are a deterministic synthetic corpus for the public classifier contract. They are generated by `generate_synthetic_cases.py` and intentionally contain the same byte-stable JSONL records.

## Provenance

Every row is independently authored from the public runner schema, classifier rules, and test contracts. It is not copied, renamed, transformed, sampled, or derived from an account export, customer record, source bill, private repository, spreadsheet, or raw transaction dataset.

The provenance is explicit in each row:

- `source` is `synthetic-public-v1`.
- `case_id` begins with `synthetic-public-v1-`.
- `tags` include `synthetic` and `public`.
- `notes` names the record as independently authored and non-bill-derived.

Values use fixed illustrative amounts and fixed 2030 UTC timestamps so the corpus has no personal, account, order, counterparty, or live-transaction linkage.

## Contract coverage

The corpus probes the classifier's public rule branches: semantic transfer, family transfer, ambiguous transfer review, platform secondary overrides, category keyword matches, keyword/destination priority, platform-misleading controls, investment-destination transfer controls, type fallback review, and the no-rule `other` fallback. It contains all runner buckets: `easy`, `edge`, `review`, and `transfer`.

## Regeneration and verification

From the repository root:

```bash
backend/.venv/bin/python evals/bill-classification-v1/generate_synthetic_cases.py
backend/.venv/bin/python -m pytest backend/tests/test_synthetic_bill_classification_corpus.py -q
```

The regression test verifies that both committed JSONL files exactly equal `render_cases()` and that provenance labels and ID prefixes are retained. The generator does not read either JSONL output or any external input.
